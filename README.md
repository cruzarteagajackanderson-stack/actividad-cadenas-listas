# Actividad: cadenas y estructuras de datos en Python

## Objetivo

Aplicar operaciones con cadenas, listas paralelas y una lista
de diccionarios mediante un programa en Python.

## Archivo principal

actividad.py

## Contenido del programa

1. Obtener una subcadena.
2. Buscar una palabra con find().
3. Reemplazar una palabra con replace().
4. Separar un texto con split().
5. Buscar la edad de una persona mediante listas paralelas.
6. Crear usuarios con nombre, email y ciudad.
7. Buscar usuarios por ciudad.
8. Ordenar alfabéticamente los nombres.
9. Validar los resultados.

## Cómo ejecutar

1. Tener Python instalado.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir actividad.py.
4. Seleccionar Run Python File in Terminal.

El programa no requiere bibliotecas adicionales.

## Resultados esperados

- Subcadena obtenida: Python.
- Posición de la palabra Python: 9.
- Edad de Marta: 19 años.
- Usuarios encontrados en Lima: 2.
- Orden alfabético: Ana, Carlos, Luis y Marta.
- Mensaje final: Todas las validaciones finalizaron correctamente.
